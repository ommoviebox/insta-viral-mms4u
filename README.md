# Insta Viral MMS4u

Starter website files for GitHub Pages. Includes black/neon styling, mobile two-column poster grid, search, categories, and a basic details page.

## Upload
Upload `index.html`, `style.css`, `app.js`, `movie.html`, and `movie.js` to the root of the `insta-viral-mms4u` repository. GitHub Pages should be configured to deploy from `main` and `/(root)`.

## Note
This is a starter template with sample titles, not a clone of private project files. Replace sample data with titles and links you are authorized to publish. A real admin panel and Firebase database need a separate Firebase project and additional setup; do not copy your old site's private credentials or reuse its database unintentionally.
